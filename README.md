# Kapildev K Portfolio

A premium dark-themed engineering portfolio built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

## Overview

This portfolio presents Kapildev K as a software engineer working across cloud security, backend engineering, DevOps, observability, endpoint compliance, and private AI systems. The visual direction stays close to a technical engineering aesthetic: dark surfaces, cyan accents, structured cards, architecture diagrams, and strong system-centric language.

## Current Scope

- Premium dark engineering interface with a technical dashboard feel
- Sticky navigation and responsive mobile menu
- About, skills, project, experience, and contact sections
- Seven featured engineering projects with rich case-study content
- Architecture-style project visuals and engineering problem summaries
- Timeline-driven experience section
- Downloadable resume and profile image assets
- SEO and social metadata setup
- Custom browser tab icon and app icon
- Reduced-motion support and accessible interaction patterns

## Project Coverage

The portfolio highlights seven major engineering efforts:

1. Private RAG Application
2. Supermarket Tally Application
3. AWS Cloud Monitoring
4. Cloud Attack Path Engine (CAPE)
5. Nethra Endpoint Compliance
6. Nethra RBAC
7. JEDAI Monitoring

## Local development

1. Install dependencies:

   npm install

2. Start the development server:

   npm run dev

3. Open http://localhost:3000 in your browser.

## Production build

npm run build

## Deployment

This project is ready for deployment on Vercel or any Node-compatible hosting platform.

1. Push the repository to GitHub.
2. Import the project in the hosting platform.
3. Use the default Next.js build settings.
4. Deploy the application.

## Assets

- Profile image: `public/profile-photo.png`
